# 우리집 관리비

로그인 없이 브라우저에 자동 저장되는 개인용 월별 관리비 계산기입니다.

## GitHub Pages에 게시하기

1. 이 폴더의 파일을 GitHub 저장소 `main` 브랜치에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
3. 자동 배포가 끝나면 Pages 주소에서 바로 사용할 수 있습니다.

입력한 정산 데이터는 서버가 아닌 사용 중인 브라우저의 Local Storage에만 저장됩니다.
